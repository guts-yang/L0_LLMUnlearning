## 2. 领域全景与演化脉络

### 2.1 一句话定位

LLM Unlearning = 在不重训的前提下，从已训练模型中移除指定数据/知识的影响，同时保持模型其余能力。它同时是**隐私合规技术**（删除权）、**内容治理技术**（版权/敏感内容）和**模型安全技术**（危险知识擦除），这三种动机的目标函数并不一致，是领域内许多矛盾的源头。

### 2.2 四阶段演化

| 阶段 | 核心问题 | 标志性工作 | 关键转折 |
|---|---|---|---|
| **2023 · 能不能忘** | 问题定义、精确遗忘、LLM 化 | SISA【4】、SCRUB【131】、GA【86】 | TOFU【143】给出第一记重击：主流基线几乎全部无效，微幅遗忘即严重损害效用 |
| **2024 · 忘得干净吗 / 会不会复活** | 方法大爆发 + 基准化 + 恢复攻击元年 | SalUn【115】、WMDP/RMU【118】、NPO【153】、SimNPO【144】、MUSE【45】、RWKU【91】 | "忘得是否可恢复"取代"能不能忘"成为核心问题 |
| **2025 · 副作用与评估可信度危机** | 修补反向优化的病态 + 审计压倒性成为主叙事 | UNDIAL【162】、FLAT【46】、EUPMU【28】、WGA/TNPO【53】、OpenUnlearning【154】、Leak@k【410】、MU-Coreset | 立场论文【21】直言：当前遗忘做的是输出抑制而非数据移除 |
| **2026 · 规模化 / 持续化 / 新架构 / 不可逆性** | 从"单次、单模态、7B、文本"迁走 | R-TOFU【525】、TFR-Net【196】、RULE/PURGE【500】【166】、量化永久遗忘【259】 | 强化遗忘独立成军；推理模型暴露"答案级目标"的系统性盲区 |

**读法**：这张表的下半段比上半段重要。领域已从"方法军备竞赛"转入"设定与度量的反思期"——**这是选择创新切口时最关键的判断**。

### 2.3 2026 最新动向（四条主线）

1. **强化遗忘（RLVR 式）从边缘走向主流**。RULE【500】把遗忘重定义为"可验证拒答"的 RL 问题；PURGE【166】用 GRPO + 可验证拒绝奖励；ReRULE【230】用离策略难例重放把算力导向 forget/retain 边界；HFRU【267】把 RL 遗忘从语言解码器移到**视觉编码器**。**核心未解风险：奖励黑客——模型学会无差别拒答，会被大多数现有指标判为成功。**
2. **推理模型（LRM）暴露"答案级目标"的系统性盲区**。R-TOFU【525】提供首个带真实 CoT 标注的基准，证明常规答案级目标在推理链里留下大量残余。**这实际是把 2024 的"文字级→语义级"缺口，在 LRM 上重演为"答案级→推理级"缺口。**
3. **不可逆性从附加指标变成设计目标**。量化永久遗忘【259】、QUAIL【348】、LoRA 集中更新抗量化【327】、再学习鲁棒【514】【264】、边际校准【200】。
4. **持续遗忘走向"容量管理"而非"顺序抑制"**。TFR-Net【196】追踪跨请求通道级风险，只压持久目标通道并**重新激活休眠通道恢复容量**，直击"反复干预耗尽保留容量"这一此前被忽视的失效模式。

## 3. 方法谱系（MECE 分类）

### 3.1 划分原则

按**"对什么对象施加什么算子"**切，而非按论文自称的流派名——因为 2024 年以来大量论文复用同一批词（preference optimization / localization / erasure）却指代完全不同的算子。

据此收敛为 **A–K 共 11 支**。其中 **J 是应用域横切轴**（与机制维度正交），**K 是 2026 新增分支**。

> **说明**：A–K 与库内【编号】对应，编号可直接定位本地 PDF。

### 3.2 谱系总表

| 分支 | 名称 | 代表方法（编号） | 算子本质 | 已知代价 / 局限 |
|---|---|---|---|---|
| **A** | 梯度上升 / 偏好优化 | GA【86】、NPO【153】、SimNPO【144】、WGA/TNPO【53】、UNDIAL【162】、AltPO【150】 | 最大化 forget loss 或其有界变体 | 无上界即崩溃；有界化后仍属"推离"范式，不解决语义挤压与再学习恢复 |
| **B** | 定位 / 稀疏 / PEFT 局部编辑 | SalUn【115】、SSD【97】、WAGLE【95】、ALTER【151】、PEFT 影响函数【52】 | 先找"该改的权重"，只改它们 | 掩码噪声大、阈值是强超参；**高遗忘比例下容量不足，反而不如全局微调** |

### 3.3 为什么把 K 独立成支

K 与 A 在算子层面根本不同：A 是**离线偏好对比 + 有界反向优化**，K 是**在线 rollout + 可验证奖励直接优化拒答行为**。训练动态、样本效率、失效模式（奖励黑客 vs 灾难性崩溃）都不同。并入 A 会掩盖 2026 最大的方法学转向。

### 4.2 逐条详解

#### C1 · 抑制 ≠ 删除（元挑战）

**本质**：几乎所有近似遗忘的损失只在**输出分布**上做"降低目标 token 概率 / 打散表征"，从未在**参数或内部表征**上定义"删除"。知识没离开模型，只是被推到概率尾部、次要主成分或未被编辑的旁路电路。

**证据链**：
- 【21】立场论文：当前遗忘做的是**输出抑制**而非训练数据移除，剖析政策与技术现实的五大错位。
- 【520】任务级指标会骗人，表征级分析揭示遗忘 = 抑制，最小微调即还原。
- 【531】注入错误/无关信息的"遗忘"实为**知识添加**。
- 【444】主流方法生成"虚假遗忘神经元"，只放大负影响。
- 【228】浅遗忘根因：编辑了**与保留集共享、微调可及**的表征子空间。
- 【264】表征**次要成分**携带残余知识，是再学习恢复的根因。
- 【349】PID 审计发现"已遗忘"信息仍可从内部表征**线性解码**。

**部分解决的思路**：把目标从输出层下沉到表征/参数层（【228】【448】【465】【278】），或把反向优化改写为良定义的最小化问题（【162】【159】【268】）。**但尚无公认的"删除"操作定义与判定标准。**

#### C2 · 再学习 / 恢复攻击（不可逆性缺失）

**本质**：遗忘把参数推到**锐利且浅**的极小值——输出概率被压低但损失景观没形成"盆地"。这不是攻击者技巧问题，是**遗忘解本身的几何性质**问题。

**证据**：【174】公开医学文章微调即恢复生化武器知识（arXiv:2406.13356, ICLR 2025）；【514】仅用 retain 集微调即可从 50% 恢复到近 100%；【27】已遗忘样本加微小扰动又能认出；【200】14 种方法的 token 边际收敛于同一窄带（**边际悬崖**）并证明其导致再学习脆弱。

**部分解决**：不变性表示【71】、权重空间正则【514】、锐度感知【446】【SAM】、边际校准【200】、max-min 对抗训练【158】。**但"不可逆"无形式化定义。**

#### C3 · 评估不可靠

**本质**：评估协议引入三个理想化偏移——(a) 贪心解码而非概率采样；(b) 单一表述而非分布级；(c) forget/retain 干净分离且随机小子集。三者叠加使指标测的是"最礼貌探针下的最好表现"。

**证据**：
- 【410】Leak@k：**几乎全部**方法在概率解码下泄漏，确定性评估给虚假安全感（arXiv:2511.04934）。
- 【MU-Coreset】只用 forget set 的 **5%（随机选也行）**即达全量效果（arXiv:2504.10185）。
- 【275】五大指标在三个 VQA 基准给出**相互矛盾**排名。
- 【512】**连精确遗忘（重训）模型的成员信息仍可被提取**——金标准被打破。

#### C4 · 遗忘–效用权衡与过度遗忘

**本质**：不是超参问题，而是**知识在参数空间叠加与纠缠**——同一神经元/方向同时承载敏感知识与通用能力。

**证据**：【416】**知识空洞**（无意制造良性知识丢失且标准基准测不到）；【404】窄域拒答遗忘触发**跨域涌现性失准**；【266】遗忘者会说谎（幻觉、异常 token、行为不一致）；【288】superposition 致重要性度量失效。

**解法最成型的一支**：偏好优化替代 GA（NPO→SimNPO→AltPO/TPO）→ token 级选择性 → 约束/几何分离（零空间投影、原始-对偶、梯度整流）。**但知识空洞与涌现性失准无系统性解法。**

#### C5–C9 要点（详见第 7 章开放问题）

- **C5**：无"模型能承受多少次遗忘"的容量界，无统一持续遗忘协议。
- **C6**：量化鲁棒**未进入任何主流基准默认评估项**。BF16 审计通过 ≠ INT4 部署安全（【54】全精度 21% → 4bit **83%**）。
- **C7**：真实设定基本无人做；更致命的是**遗忘协议本身是可武器化的攻击面**（【49】伪造样本发起对抗性遗忘请求可反向摧毁准确率；【96】提交"删除少量正常样本"的合法请求即可植入后门）。
- **C8**：除 LRM 侧有 3–4 个基准外，MoE / 扩散 LLM / 具身 / 外置记忆各仅 1–2 篇。
- **C9**：【424】证明多阶段流水线下"行为等同从头重训"不可实现，**尚无任何替代形式化目标被接受**。

### 5.3 评估指标体系

**遗忘侧**：ROUGE-L / VerBem（逐字）→ KnowMem / QA-EM / Truth Ratio（知识）→ **Forget Quality（KS p 值，对照金标）** → 概率/逐 token → **ES / EM（提取强度/精确记忆，元评估最可靠）** → MIA 家族（高忠实但脆弱）→ 攻击面审计 → 白盒/表征级探针（UNLEARNINGDEPTH、PID、激活修补）。

**效用侧**：Model Utility、KnowMem_Retain、MMLU、MT-Bench、TruthfulQA、BBH、GSM8K、邻域集、知识空洞探针、RippleBench 涟漪效应、EMA 涌现性失准。

**安全侧**：越狱成功率、拒答率与**过度拒绝**、Hair-Trigger 对齐脆弱性【179】。

**已被证明不可靠（必须加星号）**：
1. **确定性单点评估整体不可靠**（Leak@k【410】、FPE【581】、概率评估框架【617】）→ 所有概率侧指标必须注明解码策略与温度。
2. **MIA 类脆弱**：量化/再学习压力测试下失灵【154】；U-LiRA+ 揭示高估【63】；软 token 攻击不可作审计工具【193】。
3. **指标间互相矛盾**【275】【508】；**参考式指标有系统性盲区**【425】；"匹配 retrain oracle"会放过仍保留知识的模型【204】。

## 6. 跨分支张力与综合讨论

### T1 · "推离"与"删除"不等价（A 族的原生缺陷）

GA 把概率质量推离目标 token，但概率必须去某处：【BS】证明 GA 把质量挤向语义相邻的改写区（**挤压效应**），字面指标达标而语义仍在；【313】用轻量改写/多跳查询即戳破"遗忘海市蜃楼"。

C 族（RMU、LUNAR）试图绕开——不推输出、直接搬表征——但【264】证明表征**次要成分**仍携带残余知识。

> **结论**：A 与 C 之争不是精度之争，而是**"概率空间干预" vs "表征空间干预"哪个更接近删除**之争。目前证据是两者都不彻底，C 的可控性更好但深度更浅。

### T2 · 定位族 vs 全局微调：优势是条件化的，高遗忘比例下反转

【115】【95】表明小 forget set、需保效用时，稀疏/局部更新显著优于全参数；【109】却显示高影响力样本或大比例遗忘集上，SOTA 会显著偏离重训模型。**条件化结论：遗忘量小时定位占优；遗忘量大、记忆度高时，定位族因改动幅度受限而劣于全局微调**——而后者又踩过度遗忘陷阱。

### T3 · 免训练 / 轻量族在部署后攻击下系统性偏脆弱

【54】全精度保留 21% → 4bit 后 **83%**；【259】更尖锐：**"抗量化的方法几乎不改模型"**，即现有抗量化方案本身就在用免训练思路，因而无效；【327】给出的解是反过来——全参数微调变化太小撑不过 4bit，必须改用 LoRA 把更新集中到低秩子空间。

> **"改得少"既是效用优势也是鲁棒性劣势**——这是 D/F 无法同时满足的两端。

### T4 · 过度遗忘 vs 遗忘不彻底：标量化损失的固有性质

【HAMU】明确证明：加权损失组合**不保证**每个 forget/retain 样本按指定幅度改善，必然"部分欠删、部分过删"并存。而【21】的判断更根本：当前遗忘多数在做**输出抑制**而非数据移除。

### T5 · "贴近重训解"与"抗恢复"是两个不同目标，且前者有理论上限

【514】仅用 retain 集微调即可把已遗忘知识从 50% 恢复到近 100%；【424】证明"行为等同从头重训"在多阶段流水线下不可实现——**"越像重训越好"这条准则本身需要被替换**（【204】提出以"分布复原"为替代准则）。

### T6 · 所有跨分支比较都建立在被证明不可靠的指标之上

【MU-Coreset】核心集效应；【489】forget/retain 高度分离造成"虚假繁荣"；【275】五大指标给出矛盾排名。**方法谱系的任何横评结论，都必须先声明指标可信度。**

**三条已核实的关键事实**（2026-09-08 亲自核实 arXiv / ICML 官方页）：

1. **EvoMU**（arXiv:2602.02139，Pawel Batorski & Paul Swoboda，Heinrich Heine Univ. Düsseldorf）：用 **Qwen3-4B-Thinking 作为 LLM 变异算子**，进化搜索**遗忘损失 Python 代码 + 训练预算**，Top-K 选择，LoRA 微调；在 **TOFU-5%、TOFU-10%、MUSE、WMDP 上超越现有基于损失的遗忘方法**；代码开源。**配方与 MOGP-U 高度重合。**

2. **HAMU**（arXiv:2606.02119，**ICML 2026 已录用**）：从约束优化视角，把"遗忘 vs 保留"写成每步带约束的一阶凸优化；用 **κ = g_r · g_f**（retain/forget 梯度点积）同时充当硬度度量、更新方向切换开关、提前停止条件；有理论阈值 κ₁/κ₂；**实验用 Llama-2-7B + WaterDrum-TOFU + ResNet-20/CIFAR-10**；代码开源。**基座与基准和您的复现几乎完全重合。**

3. **OFMU**（arXiv:2509.22483，2025-09）：惩罚式双层优化，TOFU/WMDP/CIFAR，**已把 NPO/SimNPO/RMU/GradDiff 列为 baseline 并声称超越**。⚠️ 第三方审查（pith.science）指出**其收敛证明存在反例风险**（"a plausible empirical recipe, but the convergence proofs are invalid"）。

> **诚实结论**：如果 MOGP-U 的 abstract 写的是"现有方法用标量化加权和，我们用多目标进化搜索遗忘损失"，在 2026 年审稿环境下会被同时引 EvoMU 与 HAMU，判为 concurrent / incremental。**此外，"先复现 SimNPO 锁 SOTA"的策略在 OFMU 面前已不够——需把 OFMU 也纳入对比。**

## 9. 结论：逐条回答研究问题

**RQ1 · 方法谱系**：按"对什么对象施加什么算子"可收敛为 10 个机制分支（A 梯度上升/偏好优化、B 定位/稀疏、C 表征/子空间、D 免训练/权重算术、E 蒸馏/自蒸馏、F 上下文/推理时、G 约束/多目标、H 持续/顺序、I 可认证、K 强化/奖励驱动）+ 1 条应用域横切轴（J 跨模态跨域）。**2026 最实质的转向是 K 支独立成军。**

**RQ2 · 核心挑战**：九大挑战中，**C1（抑制≠删除）是元挑战**，其余是它在时间维、部署维、载体维、度量维上的投影；C4 是唯一独立的效用侧挑战。**「怎么忘」已充分研究，「忘没忘干净怎么判」部分解决，「在真实系统与新架构上忘」+「遗忘在理论上意味着什么」几乎无人触及。**

**RQ3 · 评估生态**：TOFU / MUSE / WMDP 三大文本基准在"目标类型 × 可验证性"上互补，是 OpenUnlearning 选它们做统一底座的原因。**虚构系与真实系数字原则上不可直接比。** ES/EM 是元评估后最可靠的指标对；MIA 高忠实但脆弱；确定性单点评估被证明系统性乐观。**做 SOTA 横评的最大陷阱是基座不一致与指标实现差异。**

**RQ4 · 2026 前沿**：四条主线——(1) 强化遗忘独立成军；(2) 推理模型暴露"答案级目标"盲区；(3) 不可逆性从附加指标变成设计目标；(4) 持续遗忘从"顺序抑制"转向"容量管理"。

**RQ5 · 创新切口**：**方向 A 的两个主卖点已被 EvoMU 与 HAMU 占据**，需换搜索对象（可忘性 / 部署不变性）或升维（部署格点）。**方向 G（ES/零阶做遗忘）经检索确认完全空白**，且与两条已发表实证（arXiv:2601.20861 证明 ES 更新大范数稠密；【327】证明全参遗忘撑不过 4bit）可拼成可证伪假设——**这是当前最干净的一个切口**。
