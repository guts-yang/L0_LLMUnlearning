## 五条核心结论

1. **领域中心问题已迁移**：2023–24 问「能不能忘」→ 2025 问「忘得是否可恢复、指标是否可信」→ 2026 问「在真实系统与新架构上怎么忘」。
2. **「抑制 ≠ 删除」是元挑战**，其余八大挑战是它在时间维、部署维、载体维、度量维上的投影。
3. **方法谱系**按时「对象 × 算子」切，收敛为 10 个机制分支 + 1 条应用域横切轴；2026 新增**强化/奖励驱动遗忘**独立成支。
4. **评估生态**：TOFU / MUSE / WMDP 三基准互补；虚构系与真实系数字不可直接比；ES/EM 是元评估后最可靠指标对。
5. **成熟度**：「怎么忘」已充分研究，「忘没忘干净怎么判」部分解决，「在真实系统与新架构上忘」+「遗忘的理论含义」几乎无人触及。
