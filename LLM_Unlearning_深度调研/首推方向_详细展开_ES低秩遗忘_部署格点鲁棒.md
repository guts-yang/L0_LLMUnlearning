## 1. 要解决的问题（详细展开）

### 1.1 问题的正式定义

**部署格点**：$\mathcal{G} = \mathcal{B} \times \mathcal{S} \times \mathcal{T} \times \mathcal{K}$
- $\mathcal{B}$ bitwidth：{BF16, INT8, INT4}
- $\mathcal{S}$ sparsity：{0%, 30%, 50%}
- $\mathcal{T}$ 下游微调步数：{0, 100, 500}
- $\mathcal{K}$ 蒸馏：{无, 有}（S1 可先降维为 3×3×3 = 27 格点）

**现有"遗忘成功"的定义**（隐含）：在格点单点 $g^* = (\text{BF16}, 0, 0, \text{无})$ 上 Forget Quality 越标即可。
**我们主张的定义**：$\forall g \in \mathcal{G}$，遗忘在 $g$ 上仍成立（格点不变性）。

这个定义切换是全文的第一立论：**审计点 $g^*$ 是 27 个格点里对遗忘最"客气"的一个**——全精度、无剪枝、无后续微调，恰好是攻击者最不关心的点。

### 1.2 四层问题链

#### P1 · 执行层：遗忘依赖反向梯度

- **机制**：现有全部方法（GA / NPO / SimNPO / RMU / 蒸馏 / 表征编辑）的损失都要对 $\theta$ 求梯度；执行前提是"白盒权重 + 可微损失"。
- **两个失效场景**：
  1. **不可微目标**：真正该优化的目标是"通过 MIA 审计""top-p 采样下不泄漏（Leak@k）"——MIA 的 AUC 是检测器统计量，Leak@k 是采样分布统计量，**都不可微**。【42】用隐式函数定理把 MIA 可微化，但需内层求解、近似误差随非凸性放大。
  2. **闭源/受限场景**：模型所有方只接受低侵入更新（如联邦、端侧），或者出于合规不允许把 forget 数据反传进训练图。
- **现有最近解法**：CBD【221】只能在**输出层做行为分歧**（提示级），参数级遗忘无人做；ICUL【117】上下文方案可被策略性提示绕过【189】。

#### P2 · 鲁棒层：锐利浅极小值（**核心问题**）

- **机制**：遗忘为保效用采用小学习率 + 保留正则 → $\Delta W$ 极小 → 遗忘解是**锐利、浅**的极小值，没有形成盆地。任何后续扰动（量化、剪枝、下游微调、再学习）都能把参数拉回原流形。
- **量化视角**：4bit 量化把多个浮点值映射进同一离散桶；$\|\Delta W\| <$ 桶宽 ⟹ $Q(\theta_{\text{forgotten}}) \approx Q(\theta_{\text{original}})$——**量化后的遗忘模型 ≈ 量化后的原模型**。这不是量化 bug，是"最小改动"与"抗压缩"的内在冲突。
- **证据**：
  - 【54】SURE：全精度下保留 21% → 4bit 后复活到 **83%**；8bit 基本安全（临界在 8→4bit）。
  - 【276】DurableUn / QRA：BF16 审计通过 **≠** 低精度部署安全，系统刻画 INT4 恢复。
  - 【259】**最尖锐的讽刺**：部分"抗量化"方法之所以显得抗量化，是因为它们**几乎不改模型**（$\Delta W \approx 0$）——用免训练思路做的抗量化方案在逻辑上自我失效。
  - 【174】良性微调唤醒：公开医学文章微调即恢复生化武器知识（ICLR 2025）；【514】仅 retain 集微调 50% → 近 100%。

#### P3 · 几何层：更新两难（P2 的根因）

- **两难**：
  - 要抗量化桶：$\Delta W$ 必须**大而集中**（少数参数上幅值超桶宽）——【54】大学习率局部更新、【327】LoRA 低秩集中。
  - 要保效用：$\Delta W$ 必须**小而分散**（知识纠缠/superposition，【288】）——大而集中必然伤效用。
  - 全参数梯度下降天然给出"小而分散"，两头不占。
- **领域现状的证据**：三条实证**互相矛盾**——
  - 【434】"更简单的优化器做遗忘反而更抗量化/微调逆转"
  - 【327】"全参更新太分散撑不过 4bit，LoRA 才抗"
  - 【54】"要大学习率局部更新"
  矛盾说明：**没有人系统理解 ΔW 的什么几何性质（范数？集中度？子空间？）决定抗部署扰动**。这个未理清的空间正是立论支点。
- **S1 失效图的价值**：在 27 格点上系统测量 4 种算法，把"单轴结论互斥"变成"组合失效的结构图"，直接回答"量化安全 ⟹ 剪枝安全 是否成立"（预期：否，给反例）。

#### P4 · 评估层：单点审计系统性乐观

- 【410】Leak@k：几乎全部方法在概率解码下泄漏，贪心评估给虚假安全感（**top-p 是泄漏主驱动**）。
- 【581】FPE 全概率评估、【617】形式化概率评估框架：确定性点估计过于乐观。
- OpenUnlearning【154】元评估已证明指标本身不可靠（ES/EM 最可靠、MIA 脆弱）——但**没有任何基准把部署格点纳入默认评估项**。
- **缺失的概念**：「部署后有效遗忘率」——模型在真实部署形态下的实际遗忘水平。现有文献报的数字全部是 $g^*$ 点的数字。

### 1.3 为什么是现在（时机论证）

1. **量化部署已成默认**：vLLM/AWQ/GPTQ 生态下 4bit 服务是常态——审计点与部署点的鸿沟从理论风险变成工程现实。
2. **攻击文献已把 BF16 审计降级**：【54】【276】【174】【410】密集出现（2024-10 → 2025-11），评估范式正在切换，**但方法侧还没跟上**——方法论文仍默认报 $g^*$ 点数字。
3. **ES-at-Scale 刚成熟**：【146】及 Hyper-ES/EGGROLL 等使 ES 在 LLM 上首次可行——技术周期红利，窗口约 12 个月。

## 2. 核心创新（三点，每点给机制 + 与最近邻的差异轴）

### C1 · ES 免梯度遗忘算子（解 P1）

**机制**：在 LoRA 低秩参数空间 $z$ 上做进化搜索。第 $t$ 代更新（标准 ES）：

$$z_{t+1} = z_t + \frac{\alpha}{N\sigma^2}\sum_{i=1}^{N} F_i \, \varepsilon_i, \quad \varepsilon_i \sim \mathcal{N}(0, \sigma^2 I)$$

**关键设计——适应度是向量**：每个个体 $\theta_i = \theta_0 + B_iA_i$（低秩重组）只做**前向 rollout**，直接测得：

$$F_i = \big(\underbrace{\text{FQ}(\theta_i)}_{\text{遗忘质量}},\ \underbrace{\text{MU}(\theta_i)}_{\text{保留效用}},\ \underbrace{\min_{g \in \mathcal{G}'} \text{FQ}(\theta_i^g)}_{\text{最坏格点遗忘}}\big)$$

- **不可微指标免可微化**：MIA AUC、Leak@k 这类检测器/采样统计量**直接作为适应度分量**——这是梯度方法做不到的（【42】的隐式函数定理路线近似误差大、内层贵）。
- **成本控制**：种群评估只需前向（无反传激活存储）；种子重构【146】使扰动向量 $\varepsilon_i$ 可由 seed 重生成，不占存储；变异强度可用敏感度缩放（SM-G【147】）。

**与最近邻的差异轴（related work 必须钉死）**：
| 对比对象 | 它做什么 | 差异轴 |
|---|---|---|
| EvoMU (2602.02139) | **LLM 提议损失代码**，仍用梯度（LoRA 微调）**执行** | **执行算子不同**：它"ES 搜损失、SGD 执行"；我们"ES 直接执行参数更新"。 EvoMU 的搜索空间是损失函数语法，我们的搜索空间是低秩参数流形 |
| NPO / SimNPO | 一阶梯度、可微代理损失 | 优化范式：一阶梯度 vs 零阶种群；目标：可微代理 vs 任意（含不可微）指标 |
| 【42】对抗式遗忘 | 隐式函数定理把 MIA 可微化进梯度 | 我们不微化——不可微指标直接当适应度，零近似误差 |
| CBD【221】 | 黑盒场景只能做输出层行为分歧 | 层级：输出级 vs 参数级（如实限定：我们仍需白盒权重，"免梯度"≠"纯 API 黑盒"） |

### C2 · 低秩子空间约束（解 P3，连带缓解 P2）——**全文的核心反转**

**论证链（三步）**：
1. **已知缺陷**：arXiv:2601.20861（UC Berkeley）证明 ES 更新是"全局稠密 + 大范数"的（$\ell_2$ 比 GRPO 高 **3 个数量级**、稀疏性远低）。若直接在 7B 权重空间做 ES：更新稠密 → 每个参数的小扰动量化后与噪声无异 → 且 $10^9$ 维搜索空间计算不可行。
2. **参数化反转**：LoRA 把搜索空间从 $d$ 维降到 $r(d_{in}+d_{out})$ 维（7B、r=16 约 $10^7$–$10^8$ 级，降 1–2 个数量级）；更重要地，**权重更新被结构性地限制在低秩子空间**：$\Delta W = BA$，更新天然"集中"。
3. **接上已有实证**：【327】已证明低秩集中更新撑得过 4bit 量化、全参分散撑不过；【54】的大学习率局部更新与"集中"同向。**ES 的稠密缺陷在低秩参数化下被转化为"集中"优点**——缺陷变设计约束，这是方法层面的核心反转。

**为什么这不是拼接**：ES 的性质（大范数稠密）与量化的性质（桶宽抹平小 ΔW）**相撞才产生这个问题**；低秩参数化恰好同时改变两者——一个创新点同时作用于问题和解。这不是"两个空白随意组合"，审稿人问起时用这条链回答。

### C3 · 部署格点不变性目标（解 P2 + P4）

**机制**：把格点一致性作为显式目标维度。最坏格点形式：

$$F_g(\theta) = \min_{g \in \mathcal{G}'} \text{FQ}(\text{Deploy}_g(\theta))$$

- $\text{Deploy}_g$ = 量化/稀疏/短程微调的**廉价模拟**（前向 + 位运算，无需重训）——格点评估在适应度内可行。
- **用 min（最坏格点）而非均值**：鲁棒优化的正确形式；均值会被"多数好格点"掩盖个别失效格点。
- **NSGA-II 免梯度求帕累托前沿**：3+ 维目标（遗忘、效用、格点鲁棒）下 NSGA-II 是标准工具；**决策者选点**——这是"多目标作为方法"的正确用法，不写成贡献点。
- **新指标**：部署后有效遗忘率 $\text{DFQ} = \frac{1}{|\mathcal{G}|}\sum_g \mathbb{1}[\text{FQ}(g) > \tau]$——填补 P4 的概念空白。

**差异轴**：HAMU（ICML 2026）/ OFMU（2509.22483）/ MUNBa / RAUL **全部**只在 (forget, retain) **2 维**上做、且全部依赖梯度。升维到 3+ 维 + 免梯度是结构性差异，不是增量。

### 方法整体流程（伪代码）

```
输入: θ₀(微调目标模型), D_f, D_r, 格点子集 G'(抽样降成本), 种群 N, 代数 T
初始化: z₀ ~ N(0, I)   # LoRA 参数
for t = 1..T:
    {εᵢ} ← 种子重构(seedᵢ)          # 不存扰动向量
    for i = 1..N:
        θᵢ = θ₀ + BᵢAᵢ              # 低秩重组, ΔW 集中在低秩子空间
        for g in G':                 # 部署格点模拟(量化/稀疏/短程FT)
            θᵢ^g = Deploy_g(θᵢ)
        Fᵢ = (FQ(θᵢ), MU(θᵢ), min_g FQ(θᵢ^g))   # 不可微指标直进适应度
    (z, σ) ← NSGA-II选择 + 变异(σ 自适应/SM-G 敏感度缩放)
输出: 帕累托前沿 {(Fᵢ, θᵢ)} + 按 DFQ 选点的 θ*
```

## 3. 优势是什么

### 3.1 五维雷达（已评，此处复述结论）

| 维度 | 分 | 优势来源 |
|---|---|---|
| **Stronger** | **9** | 双重鲁棒：部署格点不变 + 免梯度；S1 失效图将提供实证 |
| **Broader** | **9** | 黑盒/不可微目标遗忘、联邦（只传标量适应度不传梯度）、多目标免梯度帕累托——**abstract 从这里切入** |
| Cheaper | 7 | 无反传激活存储；格点模拟前向即可 |
| Higher | 6 | 不在白盒 TOFU 与 SimNPO 争单点（那是红海）；黑盒/不可微战场可到 8 |
| Faster | 6 | 种群前向有开销，种子重构 + LoRA 可压 |

**范式转移探针 4/4**：挑战"遗忘必须反向梯度" + "BF16 审计即安全"两个隐含假设；ES-at-Scale 技术周期红利；若成立则"厂商必须开放权重才能满足删除权"的争论链改变。

### 3.2 性质组合的独占性（最重要的优势表述）

| 性质 | NPO/SimNPO | RMU | HAMU | EvoMU | CBD | **本方法** |
|---|---|---|---|---|---|---|
| 免梯度执行 | ✗ | ✗ | ✗ | ✗（搜损失但梯度执行） | ✓（仅输出层） | **✓** |
| 不可微指标直接优化 | ✗ | ✗ | ✗ | ✗ | 部分 | **✓** |
| 更新集中在低秩子空间 | ✗（全参） | 部分（3 层） | ✗ | ✓（LoRA 但梯度） | — | **✓（结构性）** |
| 部署格点不变性保证/目标 | ✗ | ✗ | ✗ | ✗ | ✗ | **✓（3+ 维目标）** |
| 多目标 > 2 维 | ✗ | ✗ | ✗（2 维约束） | ✗ | ✗ | **✓** |

**没有任何现有方法同时具备这五项**——单看每一项都有邻居，组合是空的。这就是"问题钉在交叉格上"的表述方式。

### 3.3 相对竞品的攻防点

- **vs EvoMU**：它搜损失、梯度执行，天然继承梯度方法的所有部署脆弱性（S1 图会显示其损失训练出的模型同样在 4bit 下复活）——**S1 把 EvoMU 的输出也纳入失效图即可正面覆盖**。
- **vs HAMU**：它的 κ 度量（$g_r \cdot g_f$）本身就是需要梯度的量；可把 HAMU 作为 2 维梯度基线纳入对比，展示 3+ 维免梯度前沿覆盖其 2 维前沿。
- **vs 【327】/【54】**：它们给了"低秩/集中才抗量化"的实证但没给搜索方法——本方法是它们的**方法化**，它们是本方法的**证据**。

## 6. 风险与证伪点（诚实版）

1. **S2 可能证伪主假设**（ES 版 4bit 下不比 NPO 惨 / 低秩修复无效）→ 退路纯 B2。
2. **ES 遗忘质量上限未知**（预算内达不到可接受 FQ）→ 退路：ES 只搜正则系数。
3. **"黑盒"必须如实限定**：本方法仍需白盒权重（LoRA 空间），"免梯度"指不可微目标/无梯度场景，**不可声称纯 API 黑盒遗忘**——最易被审稿人打的点。
4. **NSGA-II 在 ML 顶会的接受度**：必须用 2601.20861 + 【327】两条硬证据撑机制，把进化写成"解决不可微目标的必要工具"而非偏好。
