## 二、逐挑战详解

### C1 · 抑制 ≠ 删除：知识残余与「假遗忘」

**本质**：几乎所有近似遗忘的损失函数都只在**输出分布**上做「降低目标 token 概率 / 打散表征」，从未在**参数或内部表征**上定义「删除」。因此知识并没有离开模型，只是被推到概率尾部、次要主成分或未被编辑的旁路电路里——任务级指标（准确率、ROUGE）看到的"忘了"，在白盒探针下是"压住了"。

**支撑证据**：
- 【21】立场论文直言当前机器遗忘实际做的是「输出抑制」而非「训练数据移除」，并剖析政策期望与技术现实的五大错位。
- 【520】「遗忘不是删除」：任务级指标会骗人，表征级分析揭示遗忘 = 抑制而非删除，最小幅度微调即可还原。
- 【531】往模型里注入错误/无关信息的「遗忘」实为**知识添加**而非删除，探针可区分真删与混淆。
- 【444】主流方法生成「虚假遗忘神经元」，只是放大负影响，并未真擦除。
- 【228】浅遗忘的根因是现有方法编辑的是**与保留集共享、且微调可及**的表征子空间。
- 【264】表征中的**次要成分**携带残余知识，这正是再学习能恢复的根因。
- 【349】用偏信息分解（PID）审计发现：「已遗忘」数据的信息仍可从内部表征**线性解码**。
- 【252】UNLEARNINGDEPTH 用激活修补量化知识在内部表征中的**可恢复程度**，而非仅看输出。
- 【278】遗忘留下的内部**记忆签名可跨序列泛化**，且可被手术式移除而几乎无损能力——反证它一直都在。
- 【173】遗忘会在输出中留下持久「指纹」，仅凭输出文本即可 >90% 准确率判定模型被遗忘过。
- 【566】定义「表面遗忘」：该删的互联知识没删、不该删的被删。

**部分解决？** 有，思路是**把遗忘目标从输出层下沉到表征/参数层**：表征选择性编辑【228】、激活签名抑制【350】、SAE 内部特征干预【448】【511】并把干预固化进参数【465】、机制可解释定位【69】【351】、记忆签名手术式移除【278】；另一条思路是把 GA/NPO 的**反向优化改写为良定义的最小化问题**（自蒸馏到「部分遗忘」目标分布【162】UNDIAL、注意力平滑教师【159】ASU、高惊喜 token 自蒸馏【268】SHRED），收敛点即终点、天然无塌缩。但**尚无公认的「删除」操作定义与判定标准**，这是本挑战仍开放的部分。

### C2 · 再学习 / 恢复攻击：不可逆性缺失

**本质**：遗忘把参数推到一个**锐利（sharp）且浅**的极小值——输出概率被压低，但周围损失景观没有形成"盆地"。因此任何后续梯度信号都能沿原路把参数拉回：这不是攻击者的技巧问题，而是**遗忘解本身的几何性质**问题。

**支撑证据**：
- 【174】良性再学习攻击：在公开医学文章上微调即恢复已遗忘的生化武器知识；用维基常识即逼模型吐出 Harry Potter 逐字原文。（arXiv:2406.13356，ICLR 2025）
- 【514】仅用 **retain 集**微调即可把遗忘效果从 50% 恢复到近 100%。
- 【27】已遗忘样本加**微小扰动**后模型又能认出 → 残留知识漏洞。
- 【76】成员召回攻击 MRA：仅凭遗忘后模型 + Mixup 伪装 + 知识蒸馏，把它当噪声标签器即可恢复被遗忘数据的类标签。
- 【211】POPS：**提示优化**驱动的参数震荡即可恢复 MLLM 中已遗忘的隐私知识（连权重访问都不需要）。
- 【486】步进式推理攻击：分解查询逐步诱导，绕过表面抑制。
- 【329】REBEL 用进化算法生成对抗提示，揭露良性指标把「表面抑制」误判为真遗忘。
- 【346】标准幻觉擦除陷入锐利极小值，**轻量再学习即复发**。
- 【200】发现 14 种后遗忘方法的 token 边际收敛于同一窄带（**边际悬崖**），并证明该几何规律导致再学习脆弱。
- 【446】单点遗忘损失把参数推向锐利极小值；【SAM】从锐度感知最小化视角系统研究抗再学习。
- 【160】LeakRU 把「抗泄漏」操作性地定义为**多跳路径一致性 + 恢复攻击鲁棒性**双条件。
- 【183】FRAG 用「遗忘-保留对齐间隙」比全局权重距离更准地**预测**遗忘能否扛住再学习。

**部分解决？** 是，且是本表中工程化最成功的方向：不变性表示学习【71】ILU、权重空间正则【514】、锐度感知 / 多点优化【446】【SAM】、边际校准【200】、把拒答特征消融作为内层攻击做 max-min 对抗训练【158】ERU、分层抗再学习【529】、量化鲁棒【54】。但**「不可逆」仍无形式化定义**，【457】JensUn、【494】MUDMAN 分别从 JS 散度与掩码/归一化破坏角度做了初步尝试。

### C3 · 评估不可靠：指标失效与基准假象

**本质**：评估协议本身引入了**三个理想化偏移**——(a) 贪心解码而非概率采样，(b) 单一表述形式而非分布级，(c) forget/retain 干净分离且随机小子集。三者叠加使指标测的是「在最礼貌的探针下的最好表现」，与真实部署分布系统性偏离。

**支撑证据**：
- 【410】Leak@k：**几乎全部**现有遗忘方法在概率解码下都会泄漏；确定性评估给出虚假安全感（arXiv:2511.04934）。
- 【581】全概率评估 FPE：把输入/输出分布纳入评估，指出确定性点估计**过于乐观**；【617】首个形式化概率评估框架（ICLR 2025）。
- 【MU-Coreset】**强核心集效应**：只用 forget set 的 5%（甚至随机选）就能达到全量遗忘效果，说明基准测的是「少数高影响 token」而非数据集（arXiv:2504.10185）。
- 【275】FA/RA/MIA/AD/JS 五大指标在三个 VQA 基准上给出**相互矛盾**的方法排名。
- 【193】软 token 攻击（STA）在 WMDP 上的审计结果与真实遗忘程度**背离**，作为审计工具不可靠。
- 【109】用高影响力 / 大比例遗忘集重评，SOTA 显著偏离重训模型；随机小遗忘集会**掩盖假遗忘**。
- 【273】ReMem 诊断出「阶段 1 失败」：模型**本就没记住**目标信息，遗忘评估因此不可靠。
- 【489】BLUR：现有基准 forget/retain 高度分离造成遗忘「虚假繁荣」，重叠设定撕开假象。
- 【154】OpenUnlearning 发布 450+ checkpoint 对 **12 种指标本身做忠实度元评估**（arXiv:2506.12618，NeurIPS D&B '25）。
- 【63】U-LiRA+ / TULA 揭示许多方法的遗忘效果被**高估**；【29】UQ 借鉴密码学博弈重构「遗忘质量」。
- 【512】**连精确遗忘（从头重训）也不保险**——重训模型的成员信息仍可被提取。

**部分解决？** 批判与诊断已非常充分（30+ 篇），基础设施也有了（【154】OpenUnlearning 元评估、RWKU【91】、MUSE【45】六维），但**尚未形成指标共识**：不同论文的"最佳指标"互相矛盾，且新提出的指标（Leak@k、FPE、UQ、UNLEARNINGDEPTH）各自只在自己的论文中被验证。

### C4 · 遗忘–效用权衡与过度遗忘

**本质**：这不是「超参没调好」，而是**知识在参数空间是叠加（superposition）与纠缠的**——一个神经元/方向同时承载要忘的敏感知识和要留的通用能力，因此 forget 梯度与 retain 梯度方向不可分离，任何"压低 A"的更新必然在 B 上留下分量。

**支撑证据**：
- 【143】TOFU：微幅遗忘即严重损害模型效用，主流基线极其无效（arXiv:2401.06121，ICLR 2024）。
- 【45】MUSE 六维：高遗忘率往往伴随性能崩溃或隐私泄露（arXiv:2407.06460，ICLR 2025）。
- 【153】NPO 从「灾难性崩溃」出发，证明 GA 的崩溃速度是指数级的（arXiv:2404.05868，ICLR 2025）。
- 【53】G-effect 从 Token/层/步三维揭示梯度上升因「逆置信度」机制导致灾难性遗忘（arXiv:2502.19301，ICLR 2025）。
- 【416】**知识空洞**：遗忘会无意制造良性知识的意外丢失，标准基准测不到；【197】MLLM 上同样存在且基准有盲区。
- 【404】从窄域遗忘到**涌现性失准**（EMA）：窄域拒答遗忘会触发跨域失准。
- 【266】「遗忘者会说谎」：遗忘方法常幻觉、产生异常 token 序列、行为不一致。
- 【41】输出幻觉与过度拒绝：无目标遗忘把生成分布推向均匀 → 胡言乱语；需答案保留（AP）损失兜底。
- 【387】打破「forget/retain 干净分离」假设；【321】多义困境（神经元叠加敏感数据与通用推理模式）；【288】superposition 导致参数重要性度量失效。
- 【461】纠缠感知 + 代理约束给遗忘划定原则性边界。

**部分解决？** 是，本挑战是**解法最成型**的一个，已有三代公认范式：① 偏好优化替代 GA（NPO【153】→ SimNPO【144】→ TPO/AltPO/DPO 系）；② **token 级选择性**（【156】【239】【280】【287】【507】只对 unwanted token 施加遗忘损失）；③ 约束/几何分离（零空间投影【122】【234】【270】、原始-对偶约束优化【PDU】、梯度整流【GRU】、符号门控【157】SAGO 从数学上保证合成梯度与保留方向夹角恒为锐角）。但**知识空洞与涌现性失准仍无系统性解法**。

### C5 · 顺序 / 持续遗忘：累积退化与遗忘反弹

**本质**：单次遗忘 = 在参数空间做一次「减法」。但**减法不满足交换律与结合律**：第 N 次遗忘的更新会部分撤销第 1..N-1 次的遗忘方向（遗忘反弹），同时保留侧的误差逐次累积（累积退化），最终耗尽模型的有效容量。

**支撑证据**：
- 【48】O³ 框架：正交 LoRA 隔离各遗忘任务参数空间 + 推理期软权重动态路由，避免累积效用崩溃。
- 【340】FIT：面向高频顺序遗忘请求，处理累积效用退化。
- 【291】CURaTE：实时持续遗忘，抑制累积退化并**缩短敏感信息暴露窗口**（合规视角）。
- 【196】TFGN：轨迹引导遗忘-恢复网络，阻断「遗忘干预把目标计算**重分配到剩余通路**」造成的知识复燃，并保护保留所需容量。
- 【194】MCU（多模态）：动态合并多个单次遗忘模型，缓解效用退化、**遗忘反弹**与保留漂移。
- 【45】MUSE 明确把「可持续性（sustainability over sequential requests）」列为六维之一，并证明现有算法普遍不达标。
- 【269】ICU-Bench 身份中心持续遗忘基准；【233】MLUBench 大规模 MLLM 终身遗忘基准；【601】真实版权删除请求陆续到达的顺序遗忘设定。
- 【72】NegMerge 只在多个遗忘任务间合并**符号一致**的负梯度，降低相互干扰。
- 【438】RCU 认知旋转空间量化并控制连续遗忘；【248】ICCU 用模式诱导拒答规则实现免累积损失的持续遗忘；【255】CATA 冲突规避任务算术（VLM）。

**部分解决？** 有工程方案（正交子空间 / 模型合并 / 任务算术），也有专门基准（【45】可持续性、【233】【269】【601】），但**缺少理论刻画**：没人能给出「一个模型能承受多少次遗忘」的容量界，也没有统一的持续遗忘评估协议。判定为**部分解决**。

### C6 · 部署后失效：量化 / 稀疏化 / 下游微调

**本质**：遗忘为了保住效用而采用**小学习率 + 保留集正则**，导致遗忘前后权重差 ΔW 极小；而部署侧的量化（4bit）把多个浮点值映射到**同一个离散桶**，ΔW < 桶宽即被抹平，量化后的遗忘模型 ≈ 量化后的原模型 → 知识复活。这不是量化的 bug，而是**「最小改动」与「抗压缩」两个目标的内在冲突**。

**支撑证据**：
- 【54】Catastrophic Failure of LLM Unlearning via Quantization：全精度保留 21% → 4bit 量化后回升到 **83%**（arXiv:2410.16454）。
- 【259】指出现有遗忘在 4bit 部署下普遍失效，**且抗量化方法几乎不改模型**（即"抗量化"是以无效换来的）——见反直觉清单。
- 【276】DurableUn 系统研究 INT4 量化恢复（QRA）：**BF16 审计通过 ≠ 低精度部署安全**。
- 【348】QUAIL 从**权重变化统计与量化桶重叠**角度解释低比特为何瓦解遗忘。
- 【327】全参数微调的参数变化太小撑不过 4bit，改用 LoRA 把更新集中到低秩子空间 → 量化后仍有效。
- 【333】遗忘在剪枝后的稀疏模型上效果大幅退化。
- 【434】反直觉：**更简单的优化器**做遗忘反而更抗量化/微调逆转。
- 【152】GROM 闭式解单步遗忘，天然抗量化恢复；【241】EMBER 精确编辑嵌入层抵抗对抗提示与再学习。
- 【304】「微调型遗忘**在开始前**就伤通用能力」——结构性缺陷；【179】Hair-Trigger：已对齐模型在微小微调下行为翻转，黑盒评估无法保证更新后对齐。

**部分解决？** 有，且路径清晰：**增大 ΔW 的"有效分辨率"**（显著性大学习率【54】SURE、低秩集中更新【327】、闭式解【152】、嵌入层编辑【241】、电路归因【259】、量化感知训练【348】）。但**量化鲁棒性尚未进入任何主流基准的默认评估项**，且 8bit→4bit 的临界阈值只在个别论文中被报告。

### C7 · 规模化与真实设定：预训练级、实体级、噪声 / 缺失 forget set、协议武器化

**本质**：基准把遗忘抽象成「给定干净实例级 forget set，一次删完」。真实场景是**语义级（删一个实体/概念的所有痕迹）+ 陆续到达 + forget set 本身不可得、有噪、甚至由请求方恶意构造**。更致命的是，**遗忘协议本身是一个可被武器化的攻击面**。

**支撑证据**：
- 【107】预训练 LLM 统一遗忘框架：万亿 token 场景下无法真实重训对比，只能用同分布未见数据构建「近似重训」基准。
- 【178】forget set 低质量、合成改写、水印污染等真实噪声场景。
- 【190】forget-set 与模型知识的**错配**：Under Unlearning 漏删致泄漏；Out-of-Knowledge Unlearning 逼模型「忘掉从未学过的知识」而扰动参数。
- 【605】【610】实体级（非实例级）遗忘与全景分析；【601】顺序版权删除；【182】GRACE 用少量不良行为种子自动构建 forget/retain 集，解决冷启动；【192】用模型自身合成 forget set；【293】MAGE 免 forget set；【Reload】影响估计式免遗忘集遗忘。
- 【359】Shadow Unlearning：forget set 不直接暴露给遗忘算法（防 MIA 与 PII 滥用）。
- **协议武器化**：【49】即焚遗忘——攻击者伪造非训练集样本发起「对抗性遗忘请求」，可反向操作彻底摧毁模型准确率；【96】AwoP/AwP——提交「删除少量正常样本」的**合法请求**即可砸出隐蔽后门；【128】伪装投毒把遗忘请求变成定时炸弹；【509】操纵性 forget set 借遗忘进程偷渡后门；【379】USENIX：用看似无害的对抗遗忘请求瓦解安全对齐；【342】仅 1000 条良性样本 + 前缀拒答微调即可瓦解安全对齐。
- **治理**：【21】【25】立场论文；【121】验证脆弱（劫持 SGD 轨迹或伪造重训证明即可骗过验证）；【161】验证综述（ACM CSUR 2026）指出**计算可扩展性与理论严密性的根本权衡**。

**部分解决？** 基本**没有**。实体级、噪声 forget set、免 forget set 各自只有 1-3 篇；协议武器化几乎全是**攻击论文 + 各自提出的补丁**，没有统一威胁模型或防御基准。判定为**刚提出**。

### C8 · 新架构 / 新模态：LRM CoT、MoE、扩散 LLM、MLLM、Agent、具身

**本质**：经典遗忘假设「知识 = 输入→答案的映射，编码在权重里」。新架构打破了这个假设：LRM 把知识**铺开在推理轨迹的每一步**，MoE 把知识**分片在专家路由**，MLLM 把知识**分裂在视觉/文本两侧**，Agent 把知识**外置到工具与记忆**。权重编辑只覆盖第一个载体。

**支撑证据**：
- **推理模型**：【177】LRM 遗忘的新攻击面——CoT 中间步骤的敏感信息泄漏与行为异常；【303】推理轨迹感知的选择性遗忘；【493】「忘痕迹而非答案」；【525】R-TOFU 首个带真实 CoT 标注的推理模型遗忘基准 + 步骤级指标（arXiv:2505.15214）；【352】STaR 对推理轨迹本身做调控；【289】CiPO 迭代偏好优化；【386】RMLLM 同时评估推理级泄漏与推理能力保持；【492】FUR 用遗忘推理步度量 CoT 忠实性。
- **MoE**：【235】遗忘数据不成比例激活少数专家而保留数据激活弱 → 路由-专家错配；【345】GRIP 指出现有 MoE 遗忘靠**操纵路由绕开专家**而非真擦除。
- **扩散 LLM**：【256】首个面向 LLaDA/Dream 等掩码扩散 LLM 的遗忘；【232】TimeROME-DLM 首个面向掩码扩散 LLM 的免训练推理时编辑。
- **多模态**：【36】【195】【206】【205】单模态遗忘仅**部分迁移**到 VLM；【606】模态间知识纠缠；【311】两个良性概念经特定关系连接变得不安全（关系级遗忘）；【198】属性级细粒度；【213】公私纠缠。
- **Agent / 具身 / 外置记忆**：【325】参数-记忆双通道回流问题（检索复活参数残余、记忆工件重引入敏感内容）；【188】Agentic 工具恢复；【305】Agent 隐私驱动遗忘；【302】VLA-Forget 具身基础模型；【215】有限记忆 LM 的外置知识库审计；【201】持久记忆（Kimi Delta Attention）中记录级精确删除的**否定性结果**。

**部分解决？** 基本**没有**。除 LRM 侧已有 3-4 个基准（【525】【289】【303】）外，MoE、扩散 LLM、具身、外置记忆各自**只有 1-2 篇**[未系统核实数量，基于速览笔记统计]。判定为**刚提出**。

### C9 · 理论不可能与认证–验证困境

**本质**：领域把「与从头重训不可区分」当作金标准，但这个标准本身在 LLM 上不成立——**多阶段训练流水线下重训等价不可实现**；且即使实现了，重训模型仍会泄漏成员信息。同时，「严格认证」与「可扩展到十亿参数」是一对不可兼得的目标。

**支撑证据**：
- 【424】**重训练等价的不可能性**：多阶段训练流水线下「行为等同从头重训」目标不可实现，需重新定义遗忘目标。
- 【512】打破金标准：**精确遗忘（重训）模型**的成员信息仍可被提取。
- 【141】「与重训不可区分」定义在**自适应删除请求下会泄露隐私**，必须对保留数据实施差分隐私，提出「删除隐私」新认证框架。
- 【121】验证脆弱：服务商通过最近邻样本替换劫持 SGD 轨迹或伪造重训证明，即可在未真正删除数据的情况下骗过验证；【161】验证综述（ACM CSUR 2026）建立行为观测 / 参数核验两派分类学并指出**计算可扩展性–理论严密性的根本权衡**。
- 【204】在受控 nonce-fact 测试床上证明「匹配重训 oracle」的评估准则会**放过仍保留知识的模型**。
- 【65】【47】从复杂度视角刻画「何时值得遗忘」与分布内/外遗忘的效用–复杂度权衡。
- 【539】任务向量何时可证明有效（非线性 Transformer 任务算术的泛化分析，ICLR）；【271】证明标准概念擦除是 LEACE 特例。
- 【480】反直觉：部分模型塌缩（PMC）**无需遗忘目标进损失**即可实现遗忘。
- 经典侧（已成熟但不适用于 LLM）：SISA【4】、DP 式认证【56】【78】【120】【125】、免 Hessian 在线认证【616】、可认证图遗忘【618】。

**部分解决？** 经典 ML 侧（凸/DP/图）已成熟；**LLM 侧的「重训等价不可能性」【424】是 2025-2026 才提出的否定性结果，尚无任何替代性形式化目标被社区接受**。判定为**刚提出**。

## 三、反直觉发现清单（创新富矿）

1. **抗量化的方法几乎不改模型，因而无效** —— 【259】基于电路归因的量化永久遗忘指出：现有「抗量化」遗忘在 4bit 下普遍失效，而部分自称抗量化的方法只是因为几乎没改模型权重（ΔW≈0）才"没被量化放大"。
2. **更简单的优化器做遗忘反而更鲁棒** —— 【434】「降级升级」：用更简单的优化器做遗忘，反而更抗量化与微调逆转（与"精心调参 = 更好"的直觉相反）。
3. **只忘 CoT、不删答案，反而比删答案更有效** —— 【525】R-TOFU：CoT-only 遗忘在 LRM 上综合最优，因为打断推理路径使模型**无法构造出**通往遗忘答案的中间步。
4. **强行压制推理反而暴露残余知识** —— 【525】ZeroThink / LessThink 等"少思考"解码策略，会在常规评估显示遗忘成功时泄漏已忘内容。
5. **几乎全部遗忘方法在概率解码下泄漏** —— 【410】Leak@k：贪心解码下的"成功遗忘"是假象，top-p（而非 temperature）是泄漏的主驱动因子。
6. **连"从头重训"也不安全** —— 【512】精确遗忘模型的成员信息仍可被提取，金标准本身被打破。
7. **forget set 只需 5%（随机选也行）** —— 【MU-Coreset】WMDP/MUSE 存在强核心集效应：当前遗忘由**一小撮高影响 token / 关键词**驱动，而非整个数据集。
8. **遗忘本身会留下可被读出的指纹** —— 【173】仅凭模型输出文本（甚至用 forget-无关输入）就能以 >90% 准确率判断该模型"被遗忘过"，构成新的隐私漏洞。
9. **被遗忘的 prompt 本身能被恢复，不只是答案** —— 【191】遗忘后模型对原 prompt 的响应模式泄漏其存在性。
10. **合法遗忘请求可被用来砸后门** —— 【96】攻击者仅凭提交"删除少量正常样本"的合法请求，用连续近似优化挑出恶意遗忘集，即可在遗忘过程中植入隐蔽后门；【128】伪装投毒把遗忘请求变成定时炸弹。
11. **拒答本身就是漏洞信号** —— 【604】拒答模板会暴露"刻意压制"的痕迹反遭攻击，因此需要「隐蔽遗忘」让遗忘本身不可探测；【191】同理。
12. **部分模型塌缩（PMC）无需遗忘目标进损失即可实现遗忘** —— 【480】把"模型塌缩"这一公认缺陷重新解读为遗忘的一种机制。
13. **逼模型"忘掉"它从未学过的知识也会扰动参数** —— 【190】Out-of-Knowledge Unlearning：forget set 与模型实际知识错配，会造成无谓的参数破坏。
14. **事实流行度是遗忘难度的主导因子** —— 【217】UNLamb：高频事实比低频事实**难遗忘得多**（"蒙特利尔在加拿大"这类常识最难删）；【323】DUET 用「事实流行度 × 训练阶段」二维刻画遗忘难度；【543】【542】样本级难度天然不均。
15. **单模态遗忘只部分迁移到多模态** —— 【205】语言骨干已忘的目标，**引入图像后又可恢复**；【206】跨三种 VLM 架构的双向迁移研究。

## 四、「已被充分研究」vs「尚无人解决」对照判断

### 判断依据（三条硬指标）
1. **论文数量**：该挑战下的专门论文是否 ≥ 25 篇（速览笔记中可辨识）；
2. **是否有公认解法**：是否存在 ≥2 个被多篇后续工作复用的标准化基线（如 NPO、RMU、SalUn 之于方法侧；GA/NPO/SimNPO 之于权衡侧）；
3. **是否有基准**：是否存在被社区默认采用的基准/指标（TOFU / MUSE / WMDP / RWKU / OpenUnlearning）。

### 结论表

| 挑战 | 论文量级（估） | 公认解法 | 社区基准 | 判定 |
|------|--------------|---------|---------|------|
| **C1 抑制≠删除** | 60+ | 有但不唯一（表征编辑 / SAE / 自蒸馏最小化三派并存） | 有（TOFU+MIA、RWKU 9 种攻击、LeakRU 恢复攻击） | ✅ **已充分研究**（作为"现象"充分；作为"可判定的删除定义"仍开放） |
| **C4 遗忘–效用权衡** | 80+ | **有**（NPO→SimNPO 三代偏好优化；token 级；零空间/约束优化） | 有（TOFU Forget Quality、MUSE 六维） | ✅ **已充分研究** |
| **C3 评估不可靠** | 35+ | 无共识（Leak@k / FPE / UQ / UNLEARNINGDEPTH 各自为政） | 有（OpenUnlearning 元评估，但未被默认使用） | ⚠️ **部分解决**（批判充分 → 共识未成） |
| **C2 再学习/恢复攻击** | 30+ | 有（不变性 / 权重正则 / 锐度感知 / 边际校准 / 对抗训练） | 有（【154】内置 relearn 压力测试；【160】LeakRU） | ⚠️ **部分解决**（缺"不可逆"的形式化定义） |

| **C7 规模化与真实设定** | 10-15 | **无** | **无** | ❌ **刚提出** |
| **C8 新架构/新模态** | 25+（分散在 6 个子方向，每方向 1-5 篇） | **无**（除 LRM 侧刚起步） | LRM 有（R-TOFU【525】）；MoE/扩散LLM/Agent/具身 **无** | ❌ **刚提出** |
| **C9 理论不可能与认证** | 经典侧 40+ / LLM 侧 <10 | 经典侧有（SISA/DP），LLM 侧 **无替代目标** | **无** | ❌ **刚提出**（LLM 侧） |

### 一句话总结
> **「怎么忘」已被充分研究，「忘没忘干净怎么判」部分解决，「在真实系统与新架构上忘」以及「遗忘到底在理论上意味着什么」几乎无人触及。** 后三块（C7/C8/C9 + C6 的标准化缺口）是 survey 中最值得投入的开放问题富矿。

## 六、写作建议（给 survey 正文的落点）

1. **最有力的叙事主线**：把 C1（抑制≠删除）作为「元挑战」，其余八个挑战都可视作它在**时间维（C2/C5）、部署维（C6/C7）、载体维（C8）、度量维（C3/C9）**上的投影。C4 是唯一与之独立的「效用侧」挑战。
2. **最值得强调的转折**：2024 年的共识是"遗忘方法不够好"（→ 催生 NPO/SimNPO/RMU 等方法军备竞赛）；2025-2026 的共识转向"**指标与设定本身有问题**"（Leak@k、核心集效应、重训等价不可能性、协议武器化）。survey 应把这个范式转折讲清楚。
3. **最该点名的空白**：① 量化鲁棒性未进任何基准默认项；② 持续遗忘无容量界理论；③ 实体级 / 噪声 / 免 forget set 设定无基准；④ MoE / 扩散 LLM / 具身 / 外置记忆几乎空白；⑤ LLM 侧无被接受的「重训等价」替代目标。
4. **反直觉清单最适合放在「Open Problems」小节的开头**，用 3-5 条作为"领域自满情绪的反例"，再引出开放问题。
