## 1. 谱系总览判断

这份谱系的划分原则是**按"干预发生在什么对象上、用什么算子"来切，而不是按论文自称的流派名**——因为 2024 年以来大量论文复用同一批词（"preference optimization""localization""erasure"）却指代完全不同的算子，按名分会失真。据此我把全部方法类论文收敛为 **11 个分支 A–K**。

两条关键判断需要前置说明：

**其一，A–K 并非严格同层。** A–I 与 K 是**机制维度**（对模型做什么算子），而 **J（跨模态与跨域）是"应用域"维度**，与机制维度正交：一篇 MLLM 遗忘论文可以同时属于 A（用梯度上升）和 J（作用于多模态）。强行把 J 塞进机制谱系会造成不 MECE，因此我保留 J 但明确标注它是**横切轴**而非与 A 并列的机制分支——报告中引用 J 时应表述为"某机制在域 X 上的适配"，而非独立流派。

**其二，我对用户给的草案做了两处调整。**（1）**新增 K：强化学习 / 奖励驱动遗忘族**。2025 末至 2026 出现的 RULE【500】、PURGE【166】、ReRULE【230】、HFRU【267】、ASRU【258】构成一支在算子层面与 A 根本不同的流派：A 是**离线偏好对比 + 有界反向优化**，K 是**在线 rollout + 可验证奖励直接优化拒答行为**，训练动态、样本效率、失效模式（奖励黑客 vs 灾难性崩溃）都不同，并入 A 会掩盖 2026 最大的方法学转向。（2）**把"影响函数 / 二阶曲率 / 解析闭式"从 G 挪进 D**。它们的共同算子是"不通过迭代反向优化逼近遗忘，而用代数/曲率手段直接构造目标参数"，与 D 的权重算术同源；G 则专注**多目标如何耦合**（约束、博弈、min-max）。

贯穿全部 11 支的一条主线张力是：**"把概率质量推离目标"这一动作本身不产生信息删除**。它只在推得足够"深"且"不可逆"时才近似删除，而加深必然侵蚀效用——这条张力在 A 上表现为挤压效应【BS】，在 C 上表现为表征次要成分残留【264】，在 D/F 上表现为量化与微调即恢复【54】【276】，在 K 上表现为"学会了拒答但没忘掉"。

|---|---|---|---|---|
| A | **GA（梯度上升）** | 【86】2023·[会议未核实]；TOFU 基线【143】2024·ICLR | 直接最大化遗忘集 token 的负对数似然，把对应概率打下去 | 无上界，几步即灾难性崩溃、输出乱码；【143】证明 10% 遗忘量就已失效 |
| A | **NPO（负偏好优化）** | 【153】2024·ICLR 2025 | 去掉 DPO 正样本项，只用 forget 集构造负偏好损失，自适应权重随遗忘程度自动衰减 | 依赖参考模型 ⇒ **参考模型偏置**：对不同难度样本分配优化力度不均、早期效用骤降（SimNPO【144】的核心批评） |
| A | **SimNPO** | 【144】2024·NeurIPS 2025 | 用 SimPO 式无参考模型 + 长度归一化的负偏好优化，消掉参考模型偏置 | 无参考 ⇒ 长度归一化对长回复敏感；仍属"推离"范式，不能解决语义挤压与再学习恢复 |
| A | **WGA / TNPO（G-effect 加权）** | 【53】2025·ICLR 2025 | 用 G-effect 量化梯度上升的"逆置信度"机制，导出加权 GA 与 token 级 NPO | 权重设计依赖 G-effect 统计，跨模型/跨层需重标定；本质是早停的工程化，不改"抑制"本质 |
| A | **UNDIAL（自蒸馏调 logits）** | 【162】2025·NAACL 2025 | 把原模型待忘 token 的 logit 减 γ 构成固定目标分布，自蒸馏最小化对齐，把反向优化改写成良定义的最小化问题 | γ 是全局超参，难以按样本难度自适应；对 token 级"部分遗忘"之外的语义关联擦除不足（其变体 FUNDIAL 依赖 spaCy 解析器，多语言失效） |
| A | **AltPO（交替偏好优化）** | 【150】2024·[会议未核实] | 对同一问题同时压低原答案（负反馈）+ 抬高"似真替代答案"（正反馈），让遗忘后输出合理替代而非胡言 | 需合成高质量替代答案，事实一致性靠外部模型保证；替代答案本身可能引入新幻觉 |
| A | **TPO / token 级选择性** | 【156】2025·[会议未核实]；参见【287】【239】【360】 | 把样本拆成 unwanted token 与 general token，只对前者做偏好优化、后者做保留损失 | 依赖 token 重要性估计；边界 token 的划分噪声会直接变成遗忘残留 |
| A | **CE-U / 标签平滑 GA** | 【562】2025；【419】2025 | 用统一交叉熵或标签平滑驯服 GA 的高置信梯度消失 / 低置信梯度爆炸 | 属损失形状修补，不改范式；在 50%+ 大比例遗忘上仍落后重训 |

## 3. 跨分支张力与矛盾

**T1｜"推离"与"删除"不等价——这是 A 族的原生缺陷，且不能靠调损失修好。**
梯度上升把概率质量推离目标 token，但概率必须去某处：【BS】证明 GA 把质量挤向语义相邻的改写区（**挤压效应**），字面指标达标而语义仍在；【313】用轻量改写/多跳查询即戳破"遗忘海市蜃楼"；【410】Leak@k 发现**几乎全部现有方法在概率解码（非贪心）下都泄漏**敏感内容，确定性评估给出虚假安全感。C 族的 RMU【118】与 LUNAR 试图绕开这条死路——不推输出、直接搬表征——但【264】证明表征中的**次要成分**仍携带残余知识，是再学习攻击成功的根因；【174】更进一步显示，仅在公开医学文章上做小规模良性微调即可"唤醒"已遗忘的医学知识。结论：A 与 C 之争不是精度之争，而是**"概率空间干预" vs "表征空间干预"哪个更接近删除**之争，目前证据是两者都不彻底，且 C 的可控性更好（LUNAR 的"无法回答"区域）但深度更浅。

**T2｜定位族 vs 全局微调：优势是条件化的，且高遗忘比例下会反转。**
【115】SalUn 与【95】WAGLE 表明，在**小 forget set、需保效用、需跨任务稳定**时，稀疏/局部更新显著优于全参数；【109】却显示，在**高影响力样本或大比例遗忘集**上，SOTA（含定位类）会显著偏离重训模型，说明局部更新的"容量"不够。更直接的挑战来自【214】LACUNA（首个审计"先定位后遗忘"是否在参数层真擦除的测试台）与【522】（严格检验发现局部归因→遗忘效果的因果链并不牢固）。因此条件化结论是：**遗忘量小时定位占优；遗忘量大、记忆度高、或需抗再学习时，定位族因改动幅度受限而劣于全局微调**——而后者又踩 T4 的过度遗忘陷阱。

**T3｜免训练 / 轻量族在部署后攻击下系统性偏脆弱。**
D 与 F 的核心卖点是"改得少、不伤模型"，但这正构成其鲁棒性上界。【54】SURE 与【276】DurableUn 表明**量化即可让已遗忘内容"死灰复燃"**（BF16 审计通过 ≠ INT4 部署安全）；【259】更尖锐地指出"抗量化的方法几乎不改模型"，即**现有抗量化方案本身就在用 D/F 的免训练思路，因而无效**；【327】给出的解是反过来——全参数微调的变化太小撑不过 4bit，必须改用 LoRA 把更新集中到低秩子空间。【189】与【181】则显示对抗提示即可绕过免训练抑制。反过来，【304】指出微调型遗忘"在开始前就伤通用能力"这一结构缺陷，为免训练基准辩护。**"改得少"既是效用优势也是鲁棒性劣势**——这是 D/F 无法同时满足的两端。

**T4｜过度遗忘 vs 遗忘不彻底：这不是调参问题，是标量化损失的固有性质。**
【HAMU】明确证明：加权损失组合**不保证**每个 forget/retain 样本按指定幅度改善，因此必然出现"部分欠删、部分过删"并存（【168】BalDRO 把这称为异步遗忘）。过删一端的证据密集：【41】过度拒绝、【266】"遗忘者会说谎"（幻觉与行为不一致）、【506】遗忘后遗症（退化/幻觉/过度拒答）、【416】【197】标准基准测不到的"知识空洞"、以及【404】窄域拒答遗忘触发跨域涌现性失准。欠删一端：【27】扰动样本下残留知识、【190】forget-set 与模型知识错配（Under-Unlearning 与 Out-of-Knowledge 两个方向都出错）。而【21】的立场判断更根本：当前遗忘多数在做**输出抑制**而非数据移除；【520】用表征级分析给出"遗忘=抑制而非删除、最小微调即还原"；【531】甚至指出注入错误/无关信息的"遗忘"实为**知识添加**而非删除。

**T5｜"贴近重训解"与"抗恢复"是两个不同目标，且前者有理论上限。**
【514】仅用 retain 集微调即可把已遗忘知识从 50% 恢复到近 100%；【SAM】把根因归为锐利极小值；【200】发现 14 种后遗忘方法的 token 边际收敛到同一窄带（**边际悬崖**）并证明它导致再学习脆弱；【183】FRAG 指出"遗忘关键 vs 保留关键权重的差异化影响"比全局权重距离更能预测再学习鲁棒性；【228】RepSelect 进一步定位到"编辑了与保留集共享且微调可及的表征子空间"这一浅遗忘根因。而【424】的重训练等价不可能性从理论上说明：**"行为等同从头重训"在多阶段流水线下不可实现**，因此"越像重训越好"这条准则本身需要被替换（【204】提出以"分布复原"为替代准则）。

**T6｜所有跨分支比较都建立在被证明不可靠的指标之上。**
【MU-Coreset】发现 WMDP/MUSE 等基准存在**强核心集效应**，遗忘评估被数据性质扭曲；【489】BLUR 指出 forget/retain 高度分离造成遗忘"虚假繁荣"，重叠设定下方法排名重排；【275】五大指标在三个 VQA 基准上给出**互相矛盾**的方法排名；【508】直接断言现有评估结论不可靠；【581】从全概率视角证明确定性点估计过于乐观；【154】OpenUnlearning 因此转而**对指标本身做忠实度元评估**。方法谱系的任何横评结论，都必须先声明指标可信度。

## 4. 演化脉络时间线（2023 → 2026）

**2023：能不能忘——问题定义、精确遗忘与 LLM 化起点。**
经典精确遗忘的奠基 SISA【4】（2019  preprint / S&P 2021）与综述【5】【13】【14】确立"删除权—效用—效率"三角；LLM 侧出现最早的直接微调范式【86】（GA + 随机失配 + KL 锚定）与无界遗忘 SCRUB【131】（NeurIPS 2023）。同期可认证路线【23】R2D、【56】【78】与图/联邦/推荐跨域路线【6】【2】【135】【81】并行铺开。**年末 TOFU【143】给出第一记重击：主流基线几乎全部无效，且微幅遗忘即严重损害效用。**

**2024：忘得干净吗 / 会不会复活——方法大爆发 + 基准化 + 恢复攻击元年。**
机制侧全面开花：SalUn【115】（ICLR 2024 Spotlight）把"显著性定位"变成通用件；WMDP/RMU【118】（NeurIPS 2024）把"表征误导向"推成危险知识遗忘的事实标准；NPO【153】用有界偏好优化解决崩溃，SimNPO【144】再消掉参考模型偏置；免训练侧出现 ICUL【117】、ULD【87】、ERASE【57】。基准侧 MUSE【45】、RWKU【91】、UnlearnCanvas【93】把评估从"忘没忘"扩展到六维/多对抗攻击。**同时恢复与验证攻击成为主线**：【63】U-LiRA+ 揭示虚假安全感，【27】残留知识，【121】验证脆弱，【44】数据归因删除——"忘得是否可恢复"取代"能不能忘"成为核心问题。

**2025：副作用、不可逆性与评估可信度危机。**
方法侧转向"修补反向优化的病态"：UNDIAL【162】（NAACL）把最大化改写成良定义最小化；FLAT【46】、SAGO【157】、ERU【158】（NeurIPS 2025）、EUPMU【28】（NeurIPS 2025）、WGA/TNPO【53】（ICLR 2025）、LUNAR、GROM【152】都在此列；表征侧【448】【465】【511】把 SAE 引入遗忘。**攻击与审计侧压倒性地成为主导叙事**：【174】良性再学习唤醒、【21】"遗忘并不像你想象的那样"（NeurIPS 2025 立场论文）、【410】Leak@k 概率解码失效、【MU-Coreset】核心集效应、【581】全概率评估（EMNLP 2025）、【214】LACUNA 与【522】对定位范式的严格检验、【154】OpenUnlearning 对指标本身做元评估。SemEval-2025 Task 4【589】把敏感内容遗忘变成 26 队参赛的标准化竞赛，标志该方向进入"工程基准化"阶段。

**2026：规模化 / 持续化 / 多模态与推理模型原生 / 不可逆性。**
主战场从"单次、单模态、7B、文本"迁走：（a）**持续/终身**——【196】TFR-Net、【255】CATA、【194】MCU 模型合并、【291】CURaTE、【248】ICCU；（b）**推理模型 LRM**——【525】R-TOFU（首个带 CoT 标注的基准，证明答案级目标在推理痕迹里留残余）、【493】忘痕迹而非答案、【303】【289】CiPO、【352】STaR、【177】LRM 漏洞；（c）**部署不可逆性**——量化永久遗忘【259】【276】【348】、再学习鲁棒【264】【514】【200】、抗微调恢复【228】；（d）**新架构**——MoE【235】【345】、掩码扩散 LLM【232】【256】、具身 VLA【302】、代码 LLM【220】；（e）**强化遗忘独立成军**（见下节）；（f）**系统级与 Agent**——【305】【325】【188】【ALU】。

## 5. 2026 最新方法动向

**（1）强化遗忘（RLVR 式）从边缘走向主流，成为 2026 最显著的方法学转向。** RULE【500】把遗忘重新定义为"可验证拒答"的 RL 问题，PURGE【166】用 GRPO + 可验证拒绝奖励替代外部奖励模型；2026 年的工作集中在其工程缺陷上：ReRULE【230】（arXiv 2606.15333）指出 RULE 把后期算力浪费在已收敛的易例上，用离策略难例重放把 MUSE-Books 的 Retain Quality 从 46.3 提到 56.2，额外开销仅 5%–11%；HFRU【267】（arXiv 2605.08031）把 RL 遗忘从语言解码器移到**视觉编码器**，用"对齐破坏 + GRPO 复合奖励（含抽象奖励）"在物体识别与人脸身份上做到 >98% 遗忘/保留且几乎不引入对象幻觉；ASRU【258】把激活引导与 RL 结合以约束遗忘后的生成质量；【199】（ECML-PKDD）系统证明细粒度奖励显著优于稀疏二元奖励。**这条线的核心未解风险是奖励黑客——模型学会"无差别拒答"会被大多数现有指标判为成功。**

**（2）推理模型（LRM）遗忘暴露出"答案级目标"的系统性盲区。** R-TOFU【525】提供首个带真实 CoT 标注的遗忘基准与步骤级指标，证明常规答案级目标在推理链里留下大量残余，且其 ZeroThink/LessThink 解码变体仍能泄漏已遗忘内容；【493】主张"忘痕迹而非答案"，【303】做推理轨迹感知的选择性遗忘，【289】CiPO 用迭代偏好优化平衡彻底删除与推理能力保持，【386】RMLLM 首个同时评估推理级泄漏抑制与推理能力保持的基准。**这实际上是把 2024 的"文字级→语义级"缺口，在 LRM 上重演为"答案级→推理级"缺口。**

**（3）不可逆性从"附加指标"变成"设计目标"。** 量化永久遗忘【259】基于电路归因、QUAIL【348】做量化感知遗忘、【327】用 LoRA 集中更新撑过 4bit；再学习鲁棒性方面【264】锁定表征次要成分、【514】用权重空间正则把"50%→近 100% 恢复"堵住、【200】边际校准修补边际悬崖、【SAM】用锐度感知最小化系统研究。

**（4）持续遗忘走向"容量管理"而非"顺序抑制"。** TFR-Net【196】（arXiv 2608.03123）不再只做抑制，而是追踪跨请求通道级风险、只压持久目标通道并**重新激活休眠通道恢复容量**，直击"反复干预耗尽保留所需容量"这一此前被忽视的失效模式；CATA【255】与 MCU【194】分别用冲突规避任务算术与模型合并累积请求；ICCU【248】则用上下文内拒答规则做到免累积损失。

**（5）可逆性警告升级为对范式本身的质疑。** arXiv 2606.03291（Multilingual Unlearning in LLMs，2026-06）发现跨语言遗忘迁移高度不对称，且**单个推理时 steering 方向即可跨语言恢复 50%（Qwen）/ 90%（Gemma）的已遗忘知识**——这直接把 T1 的"抑制 vs 删除"从单语推到跨语，并说明 C 族的激活干预既是遗忘手段也是最强的恢复手段。同期【425】【508】【193】继续削弱审计工具（软 token 攻击作为审计不可靠）的可信度。
