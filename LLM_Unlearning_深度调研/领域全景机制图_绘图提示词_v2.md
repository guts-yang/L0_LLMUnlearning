## 区块 1 · 左侧「输入层」（米色容器，竖排）

- 「预训练模型 M」：三层堆叠矩形图标
- 「遗忘请求」分两路：**忘集 D_f**（要删的数据，红标签）/ **留集 D_r**（要保的数据，绿标签）

## 区块 2 · 顶部「金标准对照带」（灰白横条）

- 左：重训反事实模型 `M_{-f} = Train(D \ D_f)`（Train from scratch）
- 中央目标等式（大字）：**Unlearn(M, D_f, D_r) ≈ M_{-f}**，与右侧「实际遗忘模型 M_u」以 ≈ 虚线连接
- **等式下方加红色警示小注（v2 新增）**：⚠ 重训等价在多阶段流水线下已被证明不可实现【424】；"匹配 retrain oracle"会放过仍含知识的模型【204】→ 目标需替换为可验证的删除定义

## 区块 3 · 中央「执行层」（最大区块，蓝色容器）

标题：**执行层 · 机制谱系（按「对什么对象施加什么算子」划分，10 支 + 1 横切）**

顶部共享骨架公式：`min_θ  L_f(θ;D_f) + λ·L_r(θ;D_r)`（左注"让它忘"右注"防止塌缩"），公式下加灰字注（v2 新增）：标量化加权和已被证明不保证逐样本改善【HAMU/OFMU】→ 约束 / 多目标范式

主体四列（列头沿用压/换/控/拦，每列内挂我们的谱系支）：

1. **压 Suppress**（输出概率）→ A 梯度上升/偏好族：GA → NPO → **SimNPO**（当前 SOTA baseline）；**K 强化/奖励族（v2 新增，标 2026★）**：RULE / PURGE / ReRULE
2. **换 Replace**（替换输出与表征）→ E 蒸馏族：SCRUB / FLAT / Unilogit；C 表征族：RMU / LUNAR / SAE 干预
3. **控 Locate**（定位参数与子空间）→ B 定位族：SalUn / WAGLE / ALTER；D 免训练权重算术：NegMerge / GROM / 任务向量
4. **拦 Intercept**（推理时 / 系统级）→ F 上下文族：ICUL / ERASE / Agent 工作流；解码干预：UCD / ST2U

每列底部标注已知代价（小字）：A 无上界崩溃/语义挤压｜E 教师乱码带偏能力｜B 高遗忘比例容量不足｜D 量化即复活｜F 可被绕过

- 底部绿色横条「**保留能力护栏**：Retain CE · KL 对齐 · 锚定原模型表示」→ 引出侧注：护栏过度 → 知识空洞【416】/ 跨域涌现性失准【404】
- 右侧竖标签（v2 新增）：横切轴 **J**（多模态 MLLM / 扩散 / 图 / 联邦）与 **I**（认证 / 理论极限），以细虚线挂靠主区

## 区块 4 · 元挑战横幅（红色横贯条，v2 新增，置于执行层正上方）

**「抑制 ≠ 删除」**：概率被压低 ≠ 信息被移除——元挑战 C1。向右展开四个投影小格：
C2 时间维·再学习复活 ｜ C6 部署维·量化复活 ｜ C8 载体维·新架构泄漏（CoT/MoE/外置记忆）｜ C3 度量维·指标不可靠

## 区块 5 · 底部「压力测试反馈环」（橙色虚线回路，v2 扩充为八节点）

概率采样 Leak@k（全线泄漏）→ 提示改写 → 多跳提问 → **跨语言 steering（可恢复 90%）** → **良性微调唤醒** → 4-bit 量化（21%→83%）→ LoRA 再学习 → MIA
中心问句：**知识能否被重新唤醒？——攻击后仍忘 = 遗忘合格的必要条件**
回路右端新增红色小框（v2 新增，★标注）：**部署格点 G = 位宽 × 稀疏率 × 微调 × 蒸馏，54 格 0 篇系统验证——本组主攻**
